# End O'Clock

Free, open-source Chrome extension for YouTube: pick an ending before you watch, only see videos that fit, no Shorts, cooldowns between sessions. Public repo on the owner's personal GitHub, MIT license.

## Rules

- **Mockup first for anything visual.** Before building or changing any screen, overlay, icon, mascot pose, or other visual element, make a mockup (as a claude.ai Artifact) and get the owner's approval of it. Only then implement it in the extension.
- **Character art comes from Codex.** Mascot/character image generation is done with the Codex CLI (`codex exec`), not hand-drawn SVG.
- **Mascot is original.** The clock character is inspired by 1950s atomic-age cartoons (the style Fallout's cartoons borrow) and Clippy's pop-up-helper behavior, but must not copy Vault Boy, Clippy, or any other existing character.
- **Don't use "Clockwise"** in the name, copy, or branding; this project is not affiliated with Clockwise TV.
